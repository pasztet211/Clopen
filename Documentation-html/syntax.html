Syntax

Comments

Clopen supports two types of comments:

# This is a comment
    // This is also a comment

Variables

Variables are created using let.

let name "Clopen" str
    let number 10 int

Types

Type Example
int 10
float 10.5
bool true
str "hello"
list [1,2,3]

Lists

Lists can contain multiple values.

let values [1,2,3] list

    log values[0]

Blocks

Code blocks use curly brackets.

if (x > 5) {
        log "large"
    }

Functions

fn hello(name) {
        log name
    }

Imports

with time as t
    with randint from random
