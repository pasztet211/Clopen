Clopen Errors

Overview

Clopen uses custom error types to make problems easier to identify. Errors include a description of what went wrong and where it happened.

Error Format

Errors are displayed in this format:

[Line number] ErrorType: message

Example:

[Line 8] ClopenNameError:
Variable does not exist: value

Common Errors

ClopenNameError

Happens when trying to use a variable, function, or module that does not exist. 

log $unknown

ClopenReadonlyError

Happens when trying to modify an imported or read-only value.

ClopenValueError

Happens when a value cannot be used in the current context. 

list[invalid]

ClopenTypeError

Happens when an operation is used with an incorrect type.

ClopenSyntaxError

Happens when Clopen code cannot be parsed.

Debugging Errors

The debugger can help locate errors by showing the instruction, line number, and error message. 


[Line 8] error at 'log $mariola'
ClopenNameError: Variable does not exist: mariola

Reporting Errors

If you find an error in Clopen, provide:

  • Clopen version
  • Python version
  • The code that caused the error
  • The full error message
