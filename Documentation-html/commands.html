Commands

General

let

Creates a new variable.

let number 10 int

update

Modifies an existing variable.

update number += 5

set

Changes a variable's value and type.

set number 20 int

del

Deletes a variable.

del number

User content

get

Gets input from the user.

get name "Name: "

log

Prints a value.

log "Hello"

Stopping

halt

Stops program execution.

halt

shalt

Stops execution with a different halt state.

shalt

Lists

add

Adds a value to a list.

add 6 int to end-of values

Conditionals

if

Runs code if a condition is true.

if (x > 5) {
        log "big"
    }

elif

Checks another condition if the previous one failed.

else

Runs when no previous condition matched.

Loops

while

Repeats while a condition is true.

while (x < 10) {
        update x += 1
    }

for

A loop with initialization, condition, and update.

for (i 0 int;i < 10;i += 1) {
        log i
    }

Functions

fn

Creates a function.

fn hello(name) {
        log name
    }

Imports

with

Imports Clopen modules.

with time as t

from and as

Modify how imported functions are selected or named.

with randint from random
