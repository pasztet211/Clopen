Creating Python Extensions

Making it work

If you want to make the .py file work with clopen every function has to have 2 Inputs args and local_definitions to return you should use the local definitions in this way: 


local_definitions["__return__"] = [str(value),str(value_type)]

A .py extensions needs to have a definitions dict constructed like this: 


definitions = {
    #function
    "function_name":[
        {
            "type":"fn",
            "name":"function_name",
            "inputs":[input,input],
            "native": True
            "function": function_object
        },
        "fn"
    ],
    #variable 
    "variable_name":[
        str(value),
        type(value).__name__
    ]
}

Recommendations

  • A .py file should preferably contain only functions and variable definitions at the non-function level.

No:


x = 0
x += 2

for i in range(i += 1)
    print(x)

Yes:


x = 0

def update_n_print(args,local_definitions)
    args[0] += 2

    for i in range(i += 1)
        print(args[0])

Keeping executable code inside functions makes it possible to run it in clopen

Creating Functions

Extensions should expose functionality through functions. This allows other Clopen files to import and use them safely. 


def hello(args,local_definitions)
    print("Hello from extension")

Recomended file order

  • Its recomended to put variables you want to be used by the file importing the extension at the beggining of a file and functions right after

File example:


PI = 3.14159265359
e = 2.71828182846

def sin(args,local_definitions)
    # code

definitions = {
    "sin":[
        {
            "type":"fn",
            "name":"sin",
            "inputs":["angle"],
            "native": True,
            "function": sin
        }
    ],
    "PI":[
        str(PI),
        type(PI).__name__
    ],
    "e":[
        str(e),
        type(e).__name__
    ]
}
