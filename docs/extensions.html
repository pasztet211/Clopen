Extensions

Extensions

Clopen supports extensions that add new functionality to the language. Extensions can be written in Clopen or Python.

Importing Extensions

Extensions are imported using with. 

with time as t

The as keyword creates an alias for the extension.

Python Extensions

Python extensions allow developers to create native Clopen functions. 

with randint from random

    randint number 1 10

Python extensions provide functions through a definitions dictionary.

Creating an Extension

A Python extension file must contain a definitions dictionary. 

definitions = {
        "example": [
            {
                "type": "fn",
                "name": "example",
                "inputs": [],
                "native": True,
                "function": example
            },
            "fn"
        ]
    }

Clopen Extensions

Extensions can also be written using Clopen code. 


    let value 10 int
    log value

Available Extensions

  • time - timers and sleeping
  • random - random numbers and choices
