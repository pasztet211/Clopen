Clopen Standard Library

Overview

The Clopen standard library contains official extensions that add extra functionality to the language.

Importing

Standard library modules are imported using with. 

with random
with time as t

Available Modules

random

Provides random number generation and random selection.

randint

Generates a random integer between two values. 

with randint from random

let number 0 int

randint number 1 10

log $number

choice

Selects a random value from a list. 

with choice from random

let values [1,"hello",true] list
let output "" str

choice output values

log $output

time

Provides timing functions.

time

Stores the current timer value in a variable. 

with time as t

let elapsed 0 int

t.time elapsed "seconds"

log $elapsed

sleep

Pauses program execution. 

t.sleep 1000

strings

Provides string manipulation functions.

get_char

Retrieves a character from a string at a specified index. 

with strings as sr

let string "Hello, World!" str
let char "" str

sr.get_char char string 7
log $char

length

Returns the length of a string. 

with strings as sr

let string "Hello, World!" str
let len 0 int

sr.length len string
log $len

replace_char

Replaces a character in a string at a specified index. 

with strings as sr

let string "Hello, World!" str
let new_string "" str

sr.replace_char new_string string 7 "!"
log $new_string
