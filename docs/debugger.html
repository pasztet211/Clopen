Debugger

Overview

The Clopen debugger allows you to inspect program execution and find errors in your code.

Opening the debugger

The debugger is opened using the --debug or -d argument. 

clopen --debug --basic test.clo

clopen -d --basic test.clo

Debug modes

Basic mode

Basic mode shows errors while the program runs. 


[Line 8] error at 'log $missing'
ClopenNameError: Variable does not exist: missing

Variable mode

Variable mode shows operations done to variables like creation and modification it also shows errors but doesent stop because of them 


+ x: 0 (int)
~ x: 0 -> 5
- x

Features

  • Shows the current instruction being executed
  • Displays variable changes
  • Shows errors with line numbers
  • Helps find problems in Clopen programs

Future modes

More debugging modes may be added in the future, including tools for inspecting variables, commands, and program state.

Example


let x 0 int

update x += 5

log $x

Running with the debugger will show the value changes as the program executes.
